# MAWA ERP theme update

The application now uses the shared `AppTheme.light` theme from `main.dart`.

Brand palette:
- MAWA red: `#F20D1A`
- MAWA navy: `#001A30`
- Dark red: `#C9000B`
- Soft navy: `#0B2940`

The update also replaces legacy deep-purple and indigo brand accents in authentication and approval screens while preserving semantic status colours.
